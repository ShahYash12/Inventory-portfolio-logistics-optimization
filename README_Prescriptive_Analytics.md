
# 📌 Prescriptive Analytics Portfolio – Optimization Projects using Python & Gurobi

## 🧠 Overview

This repository presents a series of prescriptive analytics case studies solved using Python and Gurobi. These projects demonstrate how mathematical modeling, optimization, and data structuring techniques can be used to make **data-driven business decisions**—a core requirement for roles in data analytics, operations research, and business strategy.

The assignments tackle real-world decision-making scenarios including **investment optimization**, **supply chain routing**, **facility location planning**, and **transshipment logistics**.

---

## 💡 Projects Included

### 1. 💰 Investment Portfolio Optimization

**Goal**: Maximize return on a $10,000 investment across 4 high-risk projects and a 5-year CD.  
**Tools**: Python, Gurobi  
**Skills**: Linear programming, constraint modeling, return maximization  
**Key Result**: Entire investment allocated to Project 1 yielded a return of **$28,000** over 5 years.

> 🔗 `Assignment1_Investment_Optimization.ipynb`

---

### 2. 🏭 Wastewater Facility Location Problem

**Goal**: Optimize the location and capacity of at most 4 wastewater treatment plants to serve 7 cities while minimizing pipeline and fixed construction costs.  
**Tools**: Python, Gurobi  
**Skills**: Facility location modeling, integer optimization, demand-based capacity planning  
**Key Insight**: Optimal plant locations determined based on population-derived wastewater loads and infrastructure costs.

> 🔗 `Assignment4_Wastewater_Facility.ipynb`

---

### 3. 🚛 Transshipment Network Optimization – *American Steel Case*

**Goal**: Minimize the monthly shipping cost of steel from two mills to four customer locations via intermediate warehouses.  
**Data**: CSV with arc capacities and costs  
**Tools**: Python, Gurobi, Pandas  
**Skills**: Network flow modeling, multistage supply chain, arc constraints with lower and upper bounds  
**Key Output**: Least-cost shipping plan meeting all demand and production constraints, while considering railcar capacity limits.

> 🔗 `Transshipment_Steel_Problem.ipynb`
